# 🐄 Catálogo Bovino Interactivo

Aplicación web interactiva para visualizar y consultar lotes de ganado en exposiciones y eventos rurales.  
Permite a los usuarios explorar fácilmente los lotes, ver miniaturas dinámicas y reproducir videos asociados.

---

## ✨ Características principales

- 📋 Listado de lotes con información relevante.
- 🎥 Miniaturas dinámicas y reproducción directa de videos.
- 🔎 Organización por categorías.
- 📱 Diseño responsive para pantallas táctiles y desktop.
- ⚡ Carga rápida y sencilla desde el navegador.

---

## 🛠️ Tecnologías utilizadas

- **Frontend:** HTML, CSS, JavaScript  
- **Integración API:** YouTube API (para thumbnails y videos)
